# Known issues

Issues the owner has run into with this setup, and what to do about them. These are not bugs to
"fix" in the configs. Read the one that matches before changing anything.

| Issue | Applies to | In short |
| --- | --- | --- |
| [Inter-OS muscle memory](inter-os-muscle-memory.md) | macOS + Windows users | Not caused by this setup. Switching between the two OSes takes practice |
| [DIP switch 6: power saving](dip-switch-6-power-saving.md) | HHKB Studio, mostly over Bluetooth | SW6 is inverted (OFF = power saving on). If the keyboard keeps sleeping, flip SW6 ON |
| [Inconsistent symbol typing on Windows](windows-inconsistent-symbols.md) | Windows, Path A | Symbols come out US ANSI. Press F19 (English) or F20 (かな) to get JIS back |
| [FKeyIME: apps keep typing English](windows-fkeyime-restart-apps.md) | Windows, Path B | Apps running during an FKeyIME install may not use it. Restart them, or sign out |
